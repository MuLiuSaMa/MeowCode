一、结论先行

🏆 省 Token 排名（设计深度 × 实战损耗）

评分=六维加权（见第三节）。MeowCode 以「防往返」系统性设计居首：一次失败编辑≈一次全上下文重发（~15k token），把失败率与复核读压到底比任何字符级优化都值钱。

⚡ 综合实力排名（功能广度 × 生态 × 成熟度）

ZCode / opencode / codex 是靠数万文件堆出来的全功能平台；MeowCode 用 ~3.2 万行拿到第一梯队的 Token 效率，属于「小而锋利」。

你的项目（MeowCode）优点在哪

  • 防往返设计最系统：编辑回执带片段 diff + File is up to date; no need to re-read.，从根上消除模型「改完再读一遍验证」的 4k+ token 复核； opponents 仅 codex/ZCode 有类似提示。
  • 编辑工具链最完整的 Token 导向：6 级匹配容错（含独有的行号前缀剥离）+ multi_edit（全有或全无）+ replaceAll + 整文件重写护栏（改动<35% 拒绝 write_file）——最后一项 6 个开源项目都没有。
  • @引用注入是七家里最省的：token 预算跟随上下文窗口（2k~12k）、均分不丢文件、同会话去重（重复 @ 只花 85 token 占位）、二进制只给路径、伪装成已发生的 read_file 调用复用同一截断器。
  • 旧工具输出淘汰（6 轮清理、保结构）且永不淘汰 edit/write 记录——「省 token」和「不忘事」同时成立，这个取舍只有 MeowCode 显式做了。
  • Prompt 缓存带优雅降级：3 个 cache 断点 + 网关不识 cache_control 时自动剥离重试，对国内中转网关兼容性最好；opencode 的 4 断点 auto 策略更激进，但无降级路径。
  • 工程密度极高：339 个测试 / 3.2 万行、tsc 零错误、两份带文件:行号的自我对比文档——单位代码质量的证据链是七家最强的。
  • Any 模型 + Windows 原生桌面：OpenAI 兼容 + Anthropic 双协议（含 thinking 块计费），Electron 桌面 + 本地会话 JSONL，数据不出本机。
